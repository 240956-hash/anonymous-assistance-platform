# Security status

This is a local engineering skeleton and is not approved for real support
requests. Do not submit personal histories, contact details or credentials in
issues, pull requests, screenshots, fixtures or logs.

Send suspected vulnerabilities privately to a project maintainer through an
existing private channel. Describe reproduction steps with fictional data.
No dedicated monitored incident-response channel is currently established.

See `docs/security/threat-model.md` for scope and open implementation tasks.
